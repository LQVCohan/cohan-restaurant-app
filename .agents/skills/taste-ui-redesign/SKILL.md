# Taste UI redesign

Use this skill for existing UI redesign, premium visual polish, mobile layout fixes, and responsive cleanup.

Read `.agents/skills/redesign-existing-projects/SKILL.md` before coding.

Rules:
- Audit the current screen first.
- Keep the existing React and SCSS stack.
- Fix shared layout root causes instead of one-off patches.
- Do not use CSS zoom for responsive work.
- On mobile, collapse secondary content and keep fixed controls from covering content.
- Test 390x844, 430x932, and one real phone.

Report files changed and validation run.
