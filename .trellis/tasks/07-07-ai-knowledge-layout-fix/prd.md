# AI knowledge manager layout fix

## Current behavior

On the manager route `#ai-chatbot-knowledge`, the knowledge list is forced into an inner viewport with its own scrollbar and compact card sizing. The action column and metadata become cramped at desktop widths. The guide card also repeats its wording because a CSS patch hides the real text and injects replacement copy through pseudo-elements for every paragraph.

## Root cause

The rendered flow is:

`restaurantAiChatbotKnowledge GraphQL query -> AiChatbotKnowledgePage.jsx -> AiChatbotAdmin.scss -> global imports in main.jsx/index.css`.

The GraphQL contract, permissions, data mapping, and UI actions are correct. Two later global styles override the base component layout:

- `AiChatbotKnowledgeCompactList.scss` adds nested scrolling and compact list constraints.
- `AiChatbotKnowledgeWordingPatch.css` replaces semantic copy with `font-size: 0` and `::after`, producing duplicate guide text and making the DOM wording differ from the visible wording.

## Scope

- Remove the compact-list global import and delete the unused stylesheet.
- Remove the wording-patch global import and delete the unused stylesheet.
- Keep the existing responsive layout, cards, forms, permissions, mutations, and data queries unchanged.

## Files changing

- `src/main.jsx`: remove the compact-list import.
- `src/index.css`: remove the wording-patch import.
- `src/styles/AiChatbotKnowledgeCompactList.scss`: delete obsolete layout override.
- `src/components/Dashboard_Manager/Customer/AiChatbotKnowledgeWordingPatch.css`: delete obsolete copy override.

## Acceptance criteria

1. The knowledge page uses normal page scrolling instead of a nested list scrollbar on desktop.
2. Knowledge cards can grow naturally so metadata, content, tags, and action buttons do not overlap or clip.
3. The guide card displays the real JSX copy once; visible wording is no longer generated by CSS pseudo-elements.
4. All knowledge actions, restaurant selection, permissions, GraphQL queries, and mutations remain unchanged.
5. Existing responsive rules in `AiChatbotAdmin.scss` remain the source of truth.

## Out of scope

- Backend schema, resolver, service, model, permission, audit, or realtime changes.
- New components, dependencies, design systems, or data behavior.
- Redesigning the other AI tabs.

## Validation plan

- Run `npm run check:conflicts`.
- Run the narrowest frontend build or component check available.
- Manually verify desktop and mobile layout when a browser runtime is available.
