# Cohan Restaurant App

## Quick start (local development)

### 1) Tạo env local
```bash
npm run env:local
```

### 2) Chạy frontend
```bash
npm run dev
```

### 3) Chạy backend
```bash
npm run dev --prefix cohan-restaurant-backend
```
