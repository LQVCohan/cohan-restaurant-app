# Demo Readiness Checklist

Use this checklist before a thesis or stakeholder demo. Mark each item only after verifying it against the exact demo environment.

## Application startup

- [ ] Backend starts successfully.
- [ ] Frontend starts successfully.
- [ ] Database connects successfully.

## Accounts and sessions

- [ ] Admin account exists.
- [ ] Login works.
- [ ] Refresh session works after browser reload.

## Security and configuration

- [ ] Captcha config matches frontend/backend settings.
- [ ] GraphQL schema validation test passes.
- [ ] User privacy tests pass.
- [ ] GraphQL depth limit tests pass.
- [ ] No real secrets are committed.

## Demo data and flows

- [ ] Upload route works if used in the demo.
- [ ] Seed/demo data is prepared.
- [ ] Browser demo flow has been tested end-to-end.
