# UC22 - Quản lý in ấn, thiết bị in và hàng đợi print job

## 1. Phạm vi

- Quản lý thiết bị in.
- Cấu hình IP/loại/vị trí.
- Phân luồng station-printer.
- Quản lý template phiếu bếp/bar/hóa đơn.
- Gửi test print.
- Theo dõi print job.
- Retry job lỗi.

## 2. Không thuộc phạm vi hiện tại

- Handshake máy in vật lý thật.
- Driver ESC/POS thật.
- Worker in nền production.
- Cloud print service.

## 3. Actor

- Quản lý nhà hàng.
- Admin hệ thống.
- Máy in LAN / thiết bị in.
- Khu vực vận hành: bếp, bar, thu ngân.
- Hàng đợi print job.

## 4. UML đề xuất

- UC22 Tổng quan quản lý in ấn.
- UC22A Quản lý thiết bị in.
- UC22B Phân luồng trạm in và mẫu phiếu.
- UC22C Hàng đợi print job và retry lỗi.

## 5. Ghi chú demo

- Test print là mô phỏng.
- Print job được lưu trong cấu hình in.
- Job lỗi có thể retry.
- Đây là đủ cho đồ án để chứng minh nghiệp vụ vận hành in.
