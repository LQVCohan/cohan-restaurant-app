# Restaurant Info Drafts

Thư mục này chứa cấu trúc dữ liệu mẫu cho bản nháp thông tin nhà hàng.
Ứng dụng hiện lưu bản nháp phía manager bằng `localStorage` key `restaurant_info_drafts_v1` để tránh mất dữ liệu khi lỗi mạng/thoát trang.

Bạn có thể dùng `restaurant-info-draft.template.json` làm mẫu khi cần import/export sau này.
